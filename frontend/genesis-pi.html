GENESIS GUILD / PLAYER SETUP

Give your screen a purpose.

A Raspberry Pi at each display. One dashboard for every location.

Connect a Raspberry Pi

  1. Install 64-bit Raspberry Pi OS Bookworm Desktop or Lite on a Pi 4 or Pi 5. Connect HDMI, Ethernet (recommended), and power.
  2. Copy the scripts folder from your Genesis Guild signage checkout to the Pi.
  3. Run sudo bash scripts/genesis-pi-setup.sh https://YOUR-SIGNAGE-HOST using your real server address. The Pi must be able to reach this address.
  4. Reboot. Player setup opens. Choose Open server player / pairing to display the pairing code.
  5. In Locations & alerts, open the correct location, choose Add Display, and enter that code.
  6. Set a settings PIN for the display. Upload images and MP4 videos, build a playlist, assign it to the display, and publish.

Keep the browser profile: it stores pairing and cached media. Use trusted HTTPS for offline caching. Let the full playlist download before testing an outage. Browser Wi-Fi signal measurements may be unavailable; heartbeat monitoring still works.

The installer configures Chromium kiosk startup and recovery. Lite uses the screentinker-kiosk systemd service. Desktop launches the kiosk at login; enable desktop autologin. Verify startup, video playback and recovery on your actual Pi before installation at a store.

Device files, server downloads & schedules

  1. Open /player/genesis.html on the Pi. Use the gear or Ctrl+Shift+S to return to setup; paired screens require their settings PIN.
  2. Select a local playlist and choose Import images & videos to copy files from the Pi or a mounted USB drive. Wait for the import to finish before disconnecting USB.
  3. Use Server-managed images & videos for the assigned published playlist, or Download assigned server media to save those files into a local playlist. Download again after server content changes.
  4. Create playlists such as Breakfast and Dinner. Under Change content at a set time, select the time zone, weekdays, times and playlist, then Add schedule.
  5. Choose the default source and Save & start playback. Outside scheduled times the default resumes. The newest matching rule wins an overlap; overnight rules start on their selected day.

Local schedules and saved media work offline once setup is cached. Request persistent storage with Keep files on this device, keep the Chromium profile, and back up originals. Import/download is limited to 512 MB per file and available storage. Export file creates a normal downloadable backup. Images use the chosen duration; videos play to the end. Local setup is per device; use Schedule content changes on a location for the server calendar.
